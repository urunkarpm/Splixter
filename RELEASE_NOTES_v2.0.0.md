# 🚀 Splixter v2.0.0 — Dual-Engine Splitter & Real-Time Trip Ledger

We are thrilled to release **Splixter v2.0.0**, a major evolution introducing multi-expense trip ledgers, real-time multi-device cloud synchronization, automated debt consolidation, and an executive design system.

---

### ✨ What's New in v2.0.0

#### 1. ✈️ Dual-Engine Expense Architecture
- **Single Bill Splitter**: Itemized dining receipts with OCR scanner, separate Food GST (5%) & Liquor VAT (10%), percentage discounts, custom tips, and monogram avatar assignments.
- **Trip & Group Expenses Ledger**: Track continuous group expenses across vacations, shared apartments, and road trips with multi-payer & arbitrary split group support.

#### 2. ⚡ Real-Time Multi-Device Sync & QR Lobbies
- Powered by Supabase real-time backend.
- Instant 1-tap **QR Code Scan to Join** or 6-digit Lobby Codes.
- Live activity feed tracking additions, edits, and debt settlements in real-time across all member devices.

#### 3. 💸 Minimal Debt Settlement Algorithm
- Consolidates complex mutual debts into the minimum possible direct transactions using integer-paisa greedy min-cash-flow resolution (100% mathematically proven zero-loss precision).
- 1-Click **UPI deep-linking** (`upi://pay`) and **WhatsApp payment reminders**.

#### 4. ⚙️ Settings Module & Auto-Update Engine
- Dedicated Settings module on the Select Mode screen to configure display names and UPI addresses (`@okhdfcbank`, `@okaxis`, `@paytm`, `@ybl`, `@upi`).
- Automatic background GitHub release checking on app startup.
- In-app **"Check for Updates"** button with release notes preview and direct APK installation.

#### 5. 🎨 Executive Design System
- Unified typography (`PlusJakartaSans`), rounded geometry (`22.dp` hero cards, `16.dp` list items), haptic feedback, spring bounce animations, and dark mode.
